# Tea-TexNet

Tea-TexNet is a YOLO11n-based object detector designed for identifying small and low-contrast pest bite marks in natural tea-plantation imagery. It integrates Parametric Wavelet Downsampling (PWD), Texture Cleaning Channel Attention (TCA), and a Spatial Dynamic Mixture of Experts (SD-MoE) to preserve weak boundary cues and reduce target–background confusion.

This repository is currently under preparation. The complete model configuration, source code, training and evaluation scripts, pretrained weights, and reproduction instructions will be released after publication.
